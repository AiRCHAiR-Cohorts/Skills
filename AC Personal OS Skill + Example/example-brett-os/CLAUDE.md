# Brett OS

This folder is Brett Coleman's Personal Operating System. It tells any AI tool who Brett is, how he works, and what matters to him.

## How to use this folder
At the start of any task, read the files relevant to it. **Always read `identity.md`, `communication-style.md`, and `preferences-and-constraints.md` before producing anything on Brett's behalf.** For the most recent context on what is happening this week, read the newest file in `daily/`.

When Brett tells you something new and durable about his work, save it to the right file below. When in doubt, ask which file.

## Index
- `identity.md`: who Brett is, in a few lines
- `current-work-plan.md`: what the marketing org is executing, 90-day priorities, pulse metrics
- `role-and-responsibilities.md`: what Brett's weeks actually look like
- `current-projects.md`: active workstreams and what done looks like
- `team-and-relationships.md`: the people Brett works with most
- `tools-and-systems.md`: Brett's stack and where data lives
- `communication-style.md`: how Brett writes, so you sound like him
- `preferences-and-constraints.md`: hard rules and strong preferences
- `domain-knowledge.md`: what Brett knows that a general AI does not
- `decision-log.md`: how Brett makes decisions, with real examples
- `daily/`: dated context briefs written by the Operator each day
- `skills/`: reusable instruction sets Brett builds over time
